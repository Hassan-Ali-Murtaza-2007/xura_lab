XURA LAB MONOGRAMS

01. X + L: the requested combined brand monogram.
02. Signature X: the simpler alternative; recommended for small browser tabs.

Both designs use the wordmark reference colors: dark forest #39463F and warm ivory #F4F3EF, with serif letterforms matched to its style.

The .svg files contain vector outlines and do not require a font to be installed.
The transparent PNGs are 1024 x 1024.
Each folder includes favicon.svg, a multi-size favicon.ico, and PNG sizes for tabs, app icons, and touch icons.
Use favicon.ico where a store asks for an ICO favicon, or icon-32.png where a store accepts PNG. Use the transparent logo files for placements that already have a background.

Created as vector artwork from serif outlines and custom letter placement. No image generation or image editing was used.
